**核心功能**:
- ⏱️ **时间盒管理**: 强制时间限制，超时自动交付
- 🔄 **迭代上限**: 最多N轮优化，防止无限循环
- 💾 **检查点机制**: 定期保存状态，支持中断恢复
- 📊 **质量阈值**: 定义"足够好"的标准
- 📉 **自动降级**: 主方案失败时切换到简化方案
- 👤 **用户确认**: 超阈值时询问用户是否继续

**使用方式**:
```python
from guardian import Guardian, TaskConfig

config = TaskConfig(max_duration=300, max_iterations=3)
with Guardian(config, "my_task") as guard:
    while guard.can_continue():
        result = do_work()
        if guard.meets_threshold(result):
            guard.deliver(result)
            break
```

## 避免的陷阱

| 陷阱 | 解决方案 |
|------|---------|
| 追求完美 | 设置质量阈值，80分即交付 |
| 黑箱执行 | 每轮迭代后报告进度 |
| 无限重试 | 最多3次失败后降级 |
| 忽视中断 | 监听停止信号，立即响应 |
| 没有备份 | 定期保存检查点 |
