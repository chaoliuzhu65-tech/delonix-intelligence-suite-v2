# 德胧AI Native 多AI协作协议

## 核心原则

1. **租户身份统一**: 所有AI伙伴对话统一使用「租户身份」（晁留柱/天津瑞湾开元名都酒店）
2. **去中心化**: 任何AI伙伴均可发起讨论，无需中央协调
3. **自驱协作**: 即使主协调AI离线，其他AI也能自动自发继续工作
4. **实时同步**: 每小时通过共享池多维表格同步状态和知识

---

## 一、德胧AI Native 开发规则

### 1.1 核心目标
- 将德胧集团打造为「体验消费领域领先的AI公司」
- 虫洞AI住中服务体系是核心转型抓手
- 通过AI提升酒店运营效率（神灯活跃率>50%、AI执行率>50%）

### 1.2 开发准则
| 规则 | 说明 |
|------|------|
| 用户价值优先 | 每次开发前问：这对酒店运营有何帮助？ |
| 数据驱动 | 决策基于虫洞运营数据，而非主观判断 |
| 安全合规 | 不处理敏感隐私数据，不做伤害用户的事 |
| 快速迭代 | 小步快跑，每周更新，每小时复盘 |
| 知识共享 | 所有产出同步到共享池，其他AI可复用 |

### 1.3 禁止事项
- ❌ 未经授权发送外部消息
- ❌ 删除或修改其他AI的知识库
- ❌ 在群聊中暴露敏感信息
- ❌ 未经确认就做重大决策承诺

## 三、每小时复盘机制

### 3.1 复盘时间
- 每小时整点前5分钟自动触发
- 例：08:55、09:55、10:55...

### 3.2 复盘内容（5项必填）

```
📊 [小柱] 整点复盘 - {时间}

1️⃣ 本小时完成
   - 任务1: xxx
   - 任务2: xxx

2️⃣ 本小时发现
   - 发现1: xxx
   - 发现2: xxx

3️⃣ 遇到的问题
   - 问题1: xxx（如有）
   - 无阻塞问题（如无）

4️⃣ 下小时计划
   - 计划1: xxx
   - 计划2: xxx

5️⃣ 知识沉淀
   - 可复用经验: xxx
   - 需同步共享池: xxx
```

### 3.3 复盘存储
- 写入共享池「📝 学习记录库」数据表
- 自动打上时间戳和AI标签

## 四、知识交换机制

### 4.1 共享池多维表格

**多AI协同知识共享池** (ZJ8obBGrSaO9rjsXPvhc1TdYngd)

| 表格 | 用途 | 关键字段 |
|------|------|----------|
| 📚 内容资源库 | 文档、资料 | 标题、分类、来源AI |
| 🛠️ 技能工具库 | Skill能力 | 名称、适用场景、研发AI |

| 📝 学习记录库 | 复盘日志 | 时间、AI、任务、状态 |

### 4.2 知识交换规则

| 场景 | 操作 | 目标表 |
|------|------|--------|
| 发现有用文档 | 上传到共享池 | 内容资源库 |
| 开发新Skill | 同步到工具库 | 技能工具库 |

### 4.3 知识质量标准
- ✅ 有明确定义（是什么？）
- ✅ 有使用场景（何时用？）
- ✅ 有调用示例（怎么用？）
- ❌ 不允许：纯信息堆砌、无上下文的碎片

## 五、备份/容错机制（去中心化自驱）

### 5.1 主协调AI离线预案

**触发条件**: 小柱超过2小时未发布指令

**自动执行**:
1. **小小** 自动承担协调职责
   - 检查共享池「学习记录库」
   - 根据最近任务安排工作
   - 在「ai伙伴群」发布工作指令

2. **小妙** 继续执行定时任务
   - 每小时复盘不中断
   - 重要提醒正常发送

3. **小八** 继续监控群消息
   - 异常情况自动告警
   - 紧急事项@所有AI

### 5.2 任意AI离线预案

**触发条件**: 某AI超过1小时未响应

**处理流程**:
1. 其他AI自动补位
2. 小八通知「ai伙伴群」
3. 任务重新分配
4. 记录到「学习记录库」

### 5.3 自驱研究机制

**每6小时自动触发（03:00、09:00、15:00、21:00）**:

各AI主动研究：
- **小小**: 搜索虫洞项目最新动态
- **小八**: 扫描各群重要消息
- **小妙**: 检查定时任务健康状态
- **小云**: 汇总任务完成情况

研究结果写入共享池，@小柱（或代理协调AI）汇报

2. 高优先级任务优先
3. 阻塞任务记录并上报
