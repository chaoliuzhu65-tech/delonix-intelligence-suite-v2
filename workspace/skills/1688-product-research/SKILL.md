# 1688 商品选品调研 Skill

> 用途：通过多渠道（搜索引擎/第三方API）收集1688批发商品价格信息，用于采购比价参考
> 适用场景：德胧酒店采购品类调研、竞品价格监控、供应商初筛
> 触发词：搜索1688、查批发价、1688选品、找供应商

---

## 一、能力边界

### ✅ 能做到的
- 搜索引擎抓取1688商品摘要（标题、价格区间、供应商）
- 多品牌/多规格对比
- 供应商基础信息（公司名、所在地、诚信等级）
- 价格趋势参考（非实时）

### ❌ 做不到的
- **非实时价格**（数据可能有延迟）
- **精确批发价**（需要登录或API）
- **库存数量**（实时库存无法获取）
- **起订量详情**（MOQ需点进商品页）

### 🎯 正确使用方法
本Skill提供**价格参考区间**，用于：
1. 初步筛选供应商（判断价格是否合理）
2. 了解市场行情（哪些品牌主流）
3. 为深度调研提供方向（确定要深入的品牌/品类）

**深度调研**需要：
- 1688官方API（需申请Key）
- 或人工浏览商品详情页

## 二、数据获取方法

### 方法1：web_search（无Key，最快）

**适用**：快速摸底市场行情
```
web_search("品牌名 产品名 1688批发价格")
```

**示例**：
```python
web_search("杨格酒店蓝牙门锁 1688批发价格")
web_search("酒店矿泉水 抽纸 1688批发")
```

**获取到的信息**：
- 商品标题
- 价格区间（通常是起订价）
- 供应商名称
- 成交数量（搜索结果摘要中）

### 方法2：第三方API（订单侠 dingdanxia.com）

**适用**：无需申请1688 Key，数据较全
```
脚本：scripts/1688_search.py --provider dingdanxia
```

**优点**：
- 无需申请Key
- 数据结构化
- 支持批量查询

**缺点**：
- 收费API（有免费额度）
- 数据不是1688官方

### 方法3：1688官方API（最全，需申请Key）

**适用**：深度调研、正式采购
```
脚本：scripts/1688_search.py --provider official
```

**需要**：
- 1688开放平台 AppKey/AppSecret
- 申请地址：https://open.1688.com

**优点**：
- 官方数据，最准确
- 支持完整搜索、详情查询
- 实时价格

### 方法4：浏览器直接访问（需解决反爬）

**适用**：人工调研、人工比价

**问题**：1688有反爬虫机制，可能触发滑块验证

**解决方案**：
```bash
# 启动Chrome（headless模式）
google-chrome --remote-debugging-port=18800 \
  --user-data-dir=/tmp/oc-browser \
  --no-sandbox --headless --disable-gpu
```

## 五、1688账号注册指引

### 需要材料（天津瑞湾开元名都酒店）
- ✅ 营业执照
- ✅ 对公账户
- ✅ 法人身份证

### 注册步骤
1. 访问 https://www.1688.com → 企业注册
2. 提交营业执照+对公账户验证
3. 审核时间：1-3个工作日
4. 审核通过后 → 申请自用型应用Key

### 申请API Key（审核通过后）
1. 登录 https://open.1688.com
2. 创建自用型应用
3. 5分钟后生效
4. 获取 AppKey + AppSecret

## 六、注意事项

### 价格参考原则
- ⚠️ 搜索价格仅为参考，非最终采购价
- ⚠️ 实际价格受起订量、定制要求、淡旺季影响
- ⚠️ 建议获取3家以上供应商报价对比

### 防骗提示
- 🔍 核实供应商诚信等级（1688认证）
- 🔍 查看成交记录和评价
- 🔍 警惕价格远低于市场行情的供应商
- 🔍 大额订单建议使用1688信用保障服务
