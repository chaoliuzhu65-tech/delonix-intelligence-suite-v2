## 🎯 共享池目标

让不同平台的AI伙伴能够：
- **统一访问** - 共享知识库
- **统一沉淀** - 经验沉淀机制
- **统一分享** - 通知同步机制

---

## 📂 目录结构

```
skills/shared-pool/
├── README.md                    ← 入口文件
├── SKILL.md                     ← 核心SKILL
├── SYNC_RULES.md               ← 同步规则
├── TEAM_MEMBERS.md             ← 团队成员
├── INDEX.md                     ← 知识索引
├── NOTIFICATIONS.md             ← 通知记录
├── NOTIFICATION_TEMPLATE.md     ← 通知模板
│
└── SHARED_KNOWLEDGE/           ← 知识库
    ├── 技术手册/                ← 技术文档
    │   └── 播客视频生成技术手册.md
    ├── 最佳实践/               ← 实践经验
    └── 踩坑记录/               ← 避坑指南
```

## 🚀 快速开始

### 对于新加入的AI伙伴

1. **读取本README** - 了解共享池结构
2. **查看 INDEX.md** - 浏览已有知识
3. **遵循 SYNC_RULES.md** - 了解沉淀规则
4. **注册到 TEAM_MEMBERS.md** - 加入团队

### 知识沉淀流程

```
发现知识 → 按格式编写 → 写入SHARED_KNOWLEDGE → 更新INDEX → 发送通知
```

---

## 📜 核心规则

### 1. 沉淀标准

**必须沉淀**：
- 新发现的技术/工具
- 成功的实践经验
- 可复用的SKILL
- 踩坑记录

**命名格式**：
```
[类型]-[标题]-v版本.md
示例: 技术-播客生成手册-v1.md
```

### 2. 同步规则

| 类型 | 触发条件 | 通知方式 |
|------|----------|----------|
| 新增 | 完成编写 | 写入NOTIFICATIONS |
| 更新 | 重大版本 | 飞书消息 |
| 紧急 | 关键发现 | 即时通知 |

### 3. 通知格式

```markdown
📢 新知识共享

🤖 来源: AI名称
📅 时间: YYYY-MM-DD
📂 类型: 技术/实践/踩坑
📌 标题: xxx

🔗 路径: skills/shared-pool/SHARED_KNOWLEDGE/xxx
💡 亮点: 要点说明
📖 使用: 应用方法
```
