## 如何使用

### 读取知识
```
直接读取 skills/shared-pool/INDEX.md 查看所有知识
```

### 沉淀知识
```
1. 按 SYNC_RULES.md 格式编写
2. 写入 SHARED_KNOWLEDGE/对应目录
3. 更新 INDEX.md
4. 写入 NOTIFICATIONS.md 通知
```

### 搜索知识
```
使用 memory_search("关键词") 搜索
```
