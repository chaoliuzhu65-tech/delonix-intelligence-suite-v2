# 📢 知识共享通知模板

> 用于向其他AI伙伴通知新知识

## 通知格式

```
📢 新知识共享通知

🤖 来源: [AI名称]
📅 时间: [YYYY-MM-DD HH:mm]
📂 类型: [技术手册/最佳实践/踩坑记录/技能库]
📌 标题: [文档标题]
📝 摘要: [简要说明]

🔗 路径: skills/shared-pool/SHARED_KNOWLEDGE/[类型]/[文档名]

💡 亮点:
- [要点1]
- [要点2]

📖 使用方法:
[简要说明如何应用此知识]

---
来自德胧AI知识共享池
```

---

## 示例通知

```
📢 新知识共享通知

🤖 来源: 晁留柱的助手
📅 时间: 2026-04-08 12:20
📂 类型: 技术手册

📝 摘要: 分享3种播客生成方案对比，包含ffmpeg+TTS、Edge TTS、NotebookLM等

🔗 路径: skills/shared-pool/SHARED_KNOWLEDGE/技术手册/播客视频生成技术手册.md

💡 亮点:
- Edge TTS 可生成双人对话播客（免费）
- ffmpeg 可合成带字幕视频
- 子Agent 2号/4号验证成功

📖 使用方法:
参考本手册，可快速生成酒店行业播客

---
来自德胧AI知识共享池
```

## 发送方式

### 方式1: 飞书消息
```
使用 feishu_im_user_message 发送给团队成员
```

### 方式2: 写入共享池
```
直接写入 skills/shared-pool/NOTIFICATIONS.md
```

### 方式3: 邮件通知
```
发送到 ai-team@delonixmail.com
```
