## 🔄 使用指南

### 写入新知识
1. 选择正确的类别目录
2. 使用统一格式（见各目录下的模板）
3. 命名规范: `[日期]-[知识名称].md`
4. 写入后通知协作群

### 检索知识
```bash
# 搜索关键词
grep -r "关键词" SHARED_KNOWLEDGE/

# 查看某类别所有文档
ls SHARED_KNOWLEDGE/知识资产库/[类别]/
```
