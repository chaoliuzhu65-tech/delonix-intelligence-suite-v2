# 图片理解技能使用指南

> 创建时间: 2026-04-10
> 作者: 晁留柱的助手（小柱）
> 适用场景: 识别图片内容、读取截图信息、理解图片文字

## 技能简介

**技能名称**: miaoda-image-understanding  
**触发词**: 图片理解、图片分析、图片识别、看图、识别图片  
**能力**: 通过 AI 分析图片内容，支持本地文件路径或 URL

---

## 使用方法

### 命令格式
```bash
miaoda-studio-cli image-understanding --image <图片路径或URL> --prompt "<分析要求>" --output <text|json>
```

### 常用场景

| 场景 | 命令 |
|------|------|
| 基础描述 | `miaoda-studio-cli image-understanding --image <path> --prompt "请描述这张图片的内容"` |
| 提取文字 | `miaoda-studio-cli image-understanding --image <path> --prompt "提取图片中的所有文字"` |
| 详细分析 | `miaoda-studio-cli image-understanding --image <path> --prompt "请详细分析这张图片"` |

---

## 实践经验（2026-04-10实测）

### ✅ 成功场景
1. **飞书文档截图** - 清晰截图识别准确
2. **纯文字内容** - 识别率接近100%
3. **聊天记录截图** - 文字+人名均可读取

### ⚠️ 注意事项
1. **网络图片URL有时限** - 建议优先使用本地文件路径
2. **长任务可能超时** - 超时30秒仍未完成会被系统终止
3. **图片清晰度影响准确率** - 模糊截图准确率下降

### ❌ 已知限制
- 飞书文档内的嵌入图片（通过token引用）无法直接访问
- 图片渲染需要额外处理（可配合飞书API下载图片）

---

## 替代方案

如 miaoda-image-understanding 不可用，可使用：
1. **飞书消息图片** - 使用 feishu_im_bot_image 工具下载后分析
2. **文档内嵌图片** - 先用 feishu_doc_media 下载，再用图片识别工具

---

## 延伸应用

结合其他技能使用：
- **+ feishu-fetch-doc**: 先读取文档文字，再识别文档内的截图
- **+ feishu-im-read**: 获取聊天记录中的图片消息，再识别
- **+ miaoda-doc-parse**: 识别文档中的复杂表格或手写内容
