## 核心价值

| 组合 | 优势 |
|------|------|
| OpenClaw | AI能力、多通道、定时任务、工具调用 |
| Obsidian | 本地Markdown、双向链接、知识图谱、插件生态 |
| **联合** | **AI自动化 + 知识沉淀 + 本地可控** |

---

## 推荐方案：文件系统直接联动（最简单）

**Vault目录结构：**
```
Obsidian Vault/
├── 00-📅 日报/
├── 01-🏨 酒店运营/
├── 02-📊 竞品分析/
├── 03-📝 会议纪要/
└── 04-🧠 AI知识/
```

**联动流程：**
```
定时触发 → OpenClaw获取数据 → AI生成内容 → 写入Obsidian Markdown
```

---

## 德胧适用场景

1. **酒店运营日报自动生成** - 每日08:00自动从飞书多维表格读取数据，生成日报
2. **会议纪要自动沉淀** - 群聊讨论自动总结，写入会议纪要笔记
3. **竞品分析知识库** - 自动创建/更新竞品卡片，支持快速检索
4. **项目知识图谱** - 双向链接建立知识网络

## 关键插件推荐

- **Dataview** - 数据库式查询和展示
- **Templater** - 强大的模板系统
- **Calendar** - 日历视图
- **Tasks** - 任务管理
- **Periodic Notes** - 周期性笔记
