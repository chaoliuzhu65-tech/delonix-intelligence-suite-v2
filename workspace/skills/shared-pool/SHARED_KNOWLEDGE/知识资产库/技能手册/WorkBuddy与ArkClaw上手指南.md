## 产品对比

| 对比项 | WorkBuddy（腾讯） | ArkClaw（字节） |
|--------|------------------|-----------------|
| **核心定位** | 内容总结问答助手 | 可执行任务的AI Agent |
| **自动化能力** | 信息总结，无法直接操作飞书 | 可读写飞书文档、创建日程、管理多维表格 |
| **部署难度** | 飞书应用市场一键安装 | 需要配置，略复杂 |
| **成本** | 企业采购，按账号 | 个人版首月9.9元起 |
| **自定义扩展** | 有限 | 完全开源，支持Skill定制 |
