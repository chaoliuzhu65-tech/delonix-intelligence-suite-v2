## 安装方法

### 第一步：安装技能

对Agent说：
```
帮我安装这个 skill：https://github.com/MiniMax-AI/skills
激活 minimax-multimodal-toolkit 技能
我的 MiniMax API Key 是 xxx，使用中国大陆服务
```

Agent会自动选择对应API节点：
- 中国大陆：`https://api.minimaxi.com`
- 全球：`https://api.minimax.io`

### 第二步：生成内容

#### 视频生成 (Hailuo 2.3)
```
生成一段视频：夕阳下，一只猫坐在窗边望向远方
```

#### 音乐生成 (Music 2.6)
```
生成一首轻快爵士风格的歌曲，主题是夏天的海边
```

#### 语音生成 (Speech 2.8)
```
用温柔女声音朗读：欢迎使用 MiniMax Token Plan
```

#### 图片生成 (Image 01)
```
生成一张赛博朋克风格的城市夜景图，16:9比例
```
