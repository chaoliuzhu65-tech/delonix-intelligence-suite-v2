## 一、已验证的技术方案

### 方案A：ffmpeg + TTS（✅ 已验证，推荐）

**技术原理**：
1. 使用agent内置TTS服务将文本转为语音
2. 用ffmpeg将音频与图片/幻灯片合成为视频
3. 可烧录字幕（srt/ass格式）

**依赖**：
- TTS服务（本agent已配置：miaoda语音模型）
- ffmpeg（系统已有）

**优点**：
- ✅ 免费，无需API Key
- ✅ 可控性强
- ✅ 可生成字幕
- ✅ 支持中文

**缺点**：
- ⚠️ 单声音，无对话感
- ⚠️ 需要手动准备PPT素材

**文件路径**：
- `/home/gem/workspace/agent/workspace/podcast_audio.mp3` - 音频
- `/home/gem/workspace/agent/workspace/podcast_episode.mp4` - 视频

- 免费，无需API Key

```bash
pip install edge-tts
```

**使用示例**：
```python
import asyncio
from edge_tts import Communicate

async def main():
    communicate = Communicate(
        text="播客脚本内容",
        voice="zh-CN-XiaoxiaoNeural"
    )
    await communicate.save("output.mp3")

asyncio.run(main())
```

## 四、视频合成命令

### 基础视频合成
```bash
ffmpeg -framerate 1 -loop 1 -i slide.png -i audio.mp3 \
  -c:v libx264 -tune stillimage -pix_fmt yuv420p \
  -shortest -movflags +faststart output.mp4
```

### 多幻灯片合成
```bash
ffmpeg -framerate 1 \
  -i "slide_%03d.png" \
  -i audio.mp3 \
  -c:v libx264 -pix_fmt yuv420p \
  -shortest output.mp4
```

### 烧录字幕
```bash
ffmpeg -i input.mp4 -vf "subtitles=subs.srt" output.mp4
```
