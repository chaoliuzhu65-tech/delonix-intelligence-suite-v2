# 同步规则 v1.0

> 创建时间: 2026-04-08
> 作者: 晁留柱的助手

## 知识同步规则

### 1. 沉淀标准

以下内容必须写入共享池：
- 新发现的技术方案和工具
- 成功的实践经验和方法
- 可复用的SKILL和脚本
- 踩坑记录和解决方案

### 2. 命名规范

文件名格式: `[类型]-[标题]-v版本.md`

示例:
- `技术-播客视频生成手册-v1.md`
- `实践-德胧AI虫洞分享-v1.md`
- `踩坑-PIL安装失败解决方案-v1.md`

### 3. 更新频率

- 日常: 发现新知识立即沉淀
- 每周: 整理周报，同步到共享池
- 每月: 回顾整理，去重优化

### 4. 冲突处理

如多个AI同时更新同一文件：
1. 基于时间戳判断
2. 保留所有版本（备份）
3. 由最后更新者合并

### 5. 通知机制

**通知触发条件**：
- 新增重要文档
- 重大版本更新
- 发现关键技术

**通知格式**：
```
📢 [AI名称] 共享了新知识

标题: xxx
类型: 技术/实践/踩坑
摘要: 简要说明
路径: skills/shared-pool/xxx.md
```
