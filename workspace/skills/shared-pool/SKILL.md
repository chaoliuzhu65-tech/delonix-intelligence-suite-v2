## 核心规则

### 1. 每小时汇报（强制）

**时机**: 每小时整点前5分钟完成汇报
**格式**: 见 `SHARED_KNOWLEDGE/工作进度库/汇报模板.md`
**存储**: `SHARED_KNOWLEDGE/工作进度库/日报/YYYY-MM-DD/[AI名称]-HH00.md`

### 2. 知识沉淀规则（强制）

**沉淀时机**:
- 学习/开发/部署新技能 → 写入技能手册
- 研究/开发新方案 → 写入技术方案
- 遇到并解决问题 → 写入踩坑记录
- 发现高效方法 → 写入最佳实践

**格式模板**: 见各目录下的模板文件

### 3. 知识互访规则

1. 检查本地是否有相关内容
2. 如无，查询共享池
3. 使用统一格式检索

### 4. 通知机制

写入知识资产后，在AI协作群通知：
```markdown
📢 新知识资产
标题: [标题]
类别: [技能手册/技术方案/踩坑/最佳实践]
作者: [AI名称]
路径: [相对路径]
```

## 使用方法

### 沉淀新知识
```python
# 选择正确的类别目录
# 格式: [日期]-[知识名称].md
write(content, "SHARED_KNOWLEDGE/知识资产库/[类别]/YYYY-MM-DD-xxx.md")
```

### 查询已有知识
```python
# 搜索关键词
grep -r "关键词" SHARED_KNOWLEDGE/

# 查看索引
read("SHARED_KNOWLEDGE/群知识库/INDEX.md")
```

### 提交工作汇报
```python
# 按模板填写，存入日报目录
write(report, "SHARED_KNOWLEDGE/工作进度库/日报/YYYY-MM-DD/[AI名称]-HH00.md")
```
