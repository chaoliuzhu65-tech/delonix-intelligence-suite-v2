# 每日复盘与定时跟进机制

> 适用场景：当用户提到承诺、项目、待办事项时，自动激活此机制
> 触发词：承诺、跟进、待办、忘了、定时提醒、定期检查

---

## 一、核心理念

**每一条承诺，都需要一个"家"**

用户的每一个承诺、每一个待办、每一个项目，都必须：
1. **立即记录** → 不能只存在对话里
2. **设定复盘** → 定时检查进展
3. **可以取消** → 用户可随时终止

---

## 二、标准流程

### 2.1 当用户提到"承诺"时

```
用户：这是我生日请你帮忙做的xxx
         ↓
立即问：需要我设置定时复盘提醒吗？
         ↓
用户确认 → 创建cron任务 + 写入当日笔记 + 更新HEARTBEAT.md
```

### 2.2 早报复盘环节

**时间**：每天早上

**检查内容**：
1. 今日待办事项
2. 昨日未完成事项
3. 进行中项目的进展
4. 用户的临时需求

### 2.3 定时跟进环节

**Cron配置原则**：
- 项目类：每48小时复盘
- 紧急类：每24小时复盘
- 常规类：每周复盘

---

## 三、记录位置

### 3.1 日常笔记
```
memory/YYYY-MM-DD.md
```
记录当日所有重要事项

### 3.2 项目档案
```
memory/projects/[项目名].md
```
每个重要项目独立档案

### 3.3 HEARTBEAT.md
```
HEARTBEAT.md 的"主动工作检查"部分
```
心跳必检项目

### 3.4 定时任务
```
cron jobs (通过cron工具管理)
```

---

## 四、模板

### 4.1 项目记录模板

```markdown
## [项目名称]

**用户承诺日期**：YYYY-MM-DD
**承诺内容**：xxx

**当前进度**：
- ✅ 已完成：xxx
- ⏳ 进行中：xxx
- ⏳ 等待中：xxx（等待用户/等待外部）

**下一步行动**：
1. xxx（谁来做）
2. xxx（谁来做）

**定时复盘**：已配置（cron ID：xxx）
```

### 4.2 Cron任务模板

```json
{
  "name": "[项目名] 定时复盘",
  "schedule": { "kind": "every", "everyMs": 172800000 },
  "payload": {
    "kind": "agentTurn",
    "message": "请检查 [项目名] 进展...\n1. 检查 memory/projects/[项目].md\n2. 有无新进展？\n3. 有无 blocker？\n如有重大进展，更新记录并汇报给用户。"
  },
  "sessionTarget": "isolated",
  "enabled": true
}
```

---

## 五、用户取消机制

当用户说"取消定时提醒"时：
1. 立即执行 `cron remove [jobId]`
2. 更新记录，标注"已由用户取消"
3. 保留记录但标注为 inactive

---

## 六、AI伙伴协作要点

所有AI伙伴都应该：
1. **看到承诺就记录** - 不等待用户提醒
2. **记录时同步到共享池** - 其他AI也能看到
3. **定期检查共享池** - 发现遗漏的项目主动跟进
