> ⚠️ **注意**：1688 API需要**企业资质**（营业执照+对公账户），个人无法申请。
> **推荐**：优先选择**京东/淘宝**开放平台，个人即可申请！详见 `jd-taobao-api-guide` Skill

> 用途：引导AI帮助用户申请1688开放平台API Key，形成可复用的标准化流程

> 触发词：申请1688 Key、1688 API、1688开放平台

## 一、申请前判断

### 1.1 确认用户是否具备条件

| 条件 | 说明 | 如不具备 |
|------|------|---------|
| 1688商家账号 | 需要已通过实名认证的1688账号 | 需要先注册1688商家账号 |
| 企业认证（推荐） | 企业账号权限更高，API调用限制更宽松 | 个人账号也可，但有限制 |

**快速判断问题**：
```
您是否有1688商家账号（已认证）？
  A. 有 → 可以直接申请自用型应用Key（5分钟拿Key）
  B. 没有 → 需要先注册1688账号（预计1-3天）
```

### 1.2 申请类型选择

| 应用类型 | 适用场景 | 审核要求 | 获取Key时间 |
|---------|---------|---------|------------|
| **自用型应用** | 自己的1688店铺数据调用 | 基础API免审核 | **5分钟** |
| 第三方应用 | 给其他商家提供API服务 | 需要审核 | 1-3天 |

## 二、自用型应用 Key 申请流程（5分钟）

### 2.1 前提条件
- ✅ 已拥有1688商家账号（个人或企业）
- ✅ 账号已完成实名认证

### 2.2 申请步骤

**Step 1: 登录开放平台**
```
网址：https://open.1688.com
方式：用1688账号登录（支持淘宝/支付宝账号登录）
```

**Step 2: 进入开发者中心**
```
位置：顶部导航栏 → "开发者中心" 或 "控制台"
```

**Step 3: 创建应用**
```
点击"创建应用" → 选择"自用型应用"
填写信息：
  - 应用名称：自定义（如"德胧采购比价系统"）
  - 应用描述：简要说明用途
  - 应用类型：网页应用/移动应用（根据实际选）
```

**Step 4: 获取 AppKey 和 AppSecret**
```
创建完成后，页面立即显示：
  - AppKey（应用标识）
  - AppSecret（应用密钥）
⚠️ 请立即保存！Secret只会显示一次
```

**Step 5: 开通需要的API权限**
```
进入"API市场" → 搜索需要的接口 → 点击"开通"
基础必备API（无需审核）：
  ✅ offer.search - 商品搜索
  ✅ alibaba.product.get - 商品详情
  ✅ item_search - 关键词搜索

高权限API（需审核1-2天）：
  ⚠️ 订单接口（目前不需要）
  ⚠️ 支付接口（目前不需要）
```

### 2.3 立即可用的API

| API | 功能 | 是否需审核 |
|-----|------|----------|
| offer.search | 商品关键词搜索 | ❌ 否 |
| alibaba.product.get | 获取商品详情/价格/SKU | ❌ 否 |
| item_search | 关键词搜索商品 | ❌ 否 |
| alibaba.quotation.get | 定制商品实时报价 | ❌ 否 |

## 三、获取Key后的配置

### 3.1 录入Key管理表

将获取的Key录入飞书多维表格 Key管理表：
```
AppKey → 填入"Key值"列
AppSecret → 安全存储，仅AI调用时使用
状态 → 改为"已配置"
```

### 3.2 测试验证

使用以下方式测试Key是否有效：
```python
# Python测试代码

APP_KEY = "您的AppKey"
APP_SECRET = "您的AppSecret"

# 测试搜索接口

    "app_key": APP_KEY,

    "pageSize": 10

# 实际调用需要签名，这里仅示意
```

## 四、常见问题处理

### 4.1 没有1688商家账号怎么办？

**方案A（推荐）**：注册新账号
```
1. 访问 https://www.1688.com → 注册
2. 选择"企业注册"或"个人注册"
3. 完成实名认证（企业需营业执照）
4. 预计1-3天完成认证
```

**方案B**：使用1688开放平台的数据服务
- 部分数据可以通过1688的开放数据平台获取
- 参考：https://data.1688.com

### 4.2 个人账号 vs 企业账号

| 对比项 | 个人账号 | 企业账号 |
|--------|---------|---------|
| API调用频率 | 较低（≤10次/秒） | 更高 |
| 高级API权限 | 受限 | 更全 |
| 认证材料 | 身份证 | 营业执照 |
| 审核时间 | 1-2天 | 2-3天 |

### 4.3 Key安全建议

⚠️ **重要**：
- AppSecret = 最高权限凭证，**禁止**硬编码在前端代码
- 建议存储在环境变量或密钥管理服务
- 定期更换Secret（每3-6个月）

## 五、AI协同要点

### 5.1 当用户说"申请1688 Key"时

1. 先问：是否有1688商家账号？
2. 有账号 → 引导进入5分钟申请流程
3. 没账号 → 说明需要先注册，介绍两种方案

### 5.2 Key申请成功后

1. 立即录入Key管理表（飞书多维表格）
2. 更新调研报告/项目文档
3. 测试API调用是否正常
4. 告知用户已配置，可开始使用

### 5.3 申请失败的处理

| 失败原因 | 解决方案 |
|---------|---------|
| 账号未认证 | 引导完成实名认证 |
| 企业资质不足 | 建议升级为企业账号 |
| 接口权限不足 | 仅需基础API可忽略，付费API需申请 |
