## 三、MVP实现讨论要点

### Q1: 值班日志助手 MVP范围
```
核心功能：
- 输入：今日关键事件（口述/文字）
- 输出：标准化值班日志模板

简化版MVP：
- 纯对话生成，不接飞书文档
- 使用预设模板填充
- 支持导出为文本

进阶版：
- 一键同步到飞书文档
- 支持交接班提醒
- 历史日志查询
```

### Q2: 客诉处理助手 MVP范围
```
核心功能：
- 输入：客诉描述（文字/语音）
- 输出：客诉类型 + 标准话术 + 处理流程

简化版MVP：
- 5类标准客诉（设施/服务/态度/卫生/安全）
- 每类3档回复话术（轻度/中度/重度）
- 固定处理流程模板

进阶版：
- 支持图片识别（客房问题拍照）
- 自动生成CRM备注
- 升级机制（店总/总部）
```

### Q3: 入住率预测 MVP范围
```
核心功能：
- 输入：日期范围
- 输出：入住率预测 + 定价建议

简化版MVP：
- 基于规则的预测（节假日/周末规律）
- 竞品价格抓取（OTA网站）
- 简单定价公式

进阶版：
- 接入德胧数据湖
- AI模型预测
- 动态定价建议
```
