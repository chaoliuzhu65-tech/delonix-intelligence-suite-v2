# [[RAG]]

## 一句话定义
Retrieval-Augmented Generation，检索增强生成，一种让 LLM 在回答时先检索相关文档片段的技术。

## 核心要点

### 工作流程
1. **索引** - 文档分块，生成向量嵌入
2. **检索** - 查询时找最相似的文档片段
3. **生成** - LLM 基于检索到的片段回答问题

### 局限性
| 问题 | 说明 |
|------|------|
| 无积累 | 每次重新检索，知识不沉淀 |
| 片段化 | 丢失文档间的关联和上下文 |
| 重复计算 | 相同文档每次都要重新处理 |

### 适用场景
- 大规模文档库（百万级以上）
- 实时性要求高的查询
- 不需要深度理解的简单问答
