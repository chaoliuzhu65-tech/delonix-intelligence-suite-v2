# [[Obsidian]]

## 一句话定义
一款基于本地 Markdown 文件的知识管理工具，支持双向链接和图谱视图。

## 核心要点

### 关键特性
- **本地优先** - 纯文本文件，无厂商锁定
- **双向链接** - `[[概念名]]` 语法
- **图谱视图** - 可视化知识关联
- **插件生态** - Web Clipper、Dataview 等

### 与 LLM Wiki 的关系
卡帕西原方案使用 Obsidian 作为：
1. raw/ 的内容编辑器
2. wiki/ 的阅读界面
3. Web Clipper 一键剪藏网页

### 替代方案
- [[OpenClaw]] - 本实现使用 OpenClaw 替代 Obsidian + Claude Code 组合
