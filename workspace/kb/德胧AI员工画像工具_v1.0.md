# 酒店行业定制版MBTI员工画像工具 v1.0

> 设计者：小柱
> 日期：2026-04-12
> 目标：让AI快速认知每个同事的性格、技能、工作偏好

---

## 一、核心维度（酒店场景定制）

### 1. 岗位适配维度

| MBTI字母 | 酒店岗位适配 |
|----------|-------------|
| E（外倾） | 前厅、GRO、销售、宴会 |
| I（内倾） | 财务、工程、厨房、后台 |
| S（实感） | 客房、管家、餐饮服务 |
| N（直觉） | 收益管理、市场策划 |
| T（思考） | 管理岗、HR、工程 |
| F（情感） | 客服、预订、客户关系 |
| J（判断） | 前台、排班管理、财务 |
| P（感知） | 销售、宴会灵活调度 |

### 2. 技能矩阵

| 技能标签 | 说明 |
|----------|------|
| 跨工种能力 | 如：前台会客房/销售会前厅 |
| 特殊技能 | 外语、急救、消防认证 |
| 管理能力 | 带团队经验 |
| 情绪稳定度 | 抗压能力评估 |

### 3. 人性化因素

| 因素 | 考虑内容 |
|------|----------|
| 三餐时间 | 是否有特殊用餐需求 |
| 家庭情况 | 是否有老人/小孩照顾需求 |
| 通勤距离 | 远距离通勤需要弹性时间 |
| 健康状态 | 体力消耗岗位需关注健康 |
| 情绪周期 | 高压岗位需定期心理关怀 |

---

## 二、使用场景

1. **排班优化**：技能互补+性格兼容组合
2. **任务分配**：根据性格匹配难缠客户
3. **情绪预警**：高T高J员工需注意情绪疏导
4. **团队搭配**：外倾+内倾互补

---

## 三、数据来源

- 花名册（基础信息）
- 工资表（部门/岗位）
- 排班记录（历史出勤）
- 直接对话（性格判断）
