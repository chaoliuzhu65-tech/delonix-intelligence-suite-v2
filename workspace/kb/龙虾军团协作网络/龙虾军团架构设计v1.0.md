## 四、一对多任务机制

### 任务分解流程
```
用户 → 接收龙虾 → 分解为N个子任务 → 分派给N个子龙虾 → 并行执行 → 汇总反馈
```

### 任务分解规则
| 任务类型 | 分解方式 | 子任务数 |
|----------|----------|----------|
| 简单查询 | 单子龙虾直办 | 1 |
| 多独立任务 | 并行分解 | N（≤8） |
| 复杂单任务 | 串行分解 | M（按阶段） |
| 超复杂任务 | 多龙虾协同 | N×M |

### 反馈机制
- **子龙虾 → 母龙虾**: 完成/失败/阻塞 立即上报
- **母龙虾 → 用户**: 汇总整编后统一回复
- **超时规则**: 单子任务超时5分钟自动降级/升级

## 五、防死循环机制

### Anti-Deadloop Guardian 集成

每只龙虾的"守守"子龙虾内置防死机制：

| 防护层 | 机制 | 阈值 |
|--------|------|------|
| **时间盒** | 任务最大执行时间 | 5分钟 |
| **迭代上限** | 单任务最大循环 | 3次 |
| **检查点** | 每60秒保存进度 | 自动 |
| **质量阈值** | 达标即交付 | 80分 |
| **升级通道** | 超限自动上报 | 2次后 |

### 拥堵防控
- **平台消息队列**: 每只龙虾最多缓存10条待处理消息
- **优先级队列**: 紧急>高>中>低
- **超时回收**: 10分钟未反馈的任务自动重新分配
- **死任务标记**: 3次失败标记为"死任务"人工介入

- **协议**: 飞书私信
