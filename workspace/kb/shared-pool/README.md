## 同步机制

### 双向同步流程

```
本地 Wiki 变更 ──────┐
                    ├──► 飞书共享池 (中央存储)
其他 AI 更新 ────────┘          │
                               ▼
                    广播同步到所有 AI 实例
```

### 同步触发条件

| 场景 | 触发方式 | 同步方向 |
|------|----------|----------|
| 用户存入 raw/ 文件 | 即时 | 本地 → 共享池 |
| 其他 AI 更新知识 | Webhook | 共享池 → 本地 |
| 定时整理 | Cron (每15分钟) | 双向检查 |
| 手动强制同步 | 指令触发 | 双向 |

## 共享池存储结构

### 飞书多维表格设计

**表1: 概念库 (Concepts)**
```
- 概念ID (唯一)
- 概念名
- 定义摘要
- 完整内容 (Markdown)
- 来源AI (OpenID)
- 创建时间
- 更新时间
- 版本号
- 标签
```

**表2: 链接图谱 (Links)**
```
- 链接ID
- 源概念
- 目标概念
- 关系类型 (引用/相关/扩展)
- 创建时间
```

**表3: 变更日志 (Changelog)**
```
- 日志ID
- 操作类型 (新增/更新/删除)
- 概念名
- 操作AI (OpenID)
- 时间戳
- 变更摘要
```

**表4: AI 实例注册表 (Agents)**
```
- OpenID
- 昵称
- 负责方向
- 最后同步时间
- 状态 (在线/离线)
```

## 协作协议

### 知识贡献规范

1. **命名空间**
   - 通用知识: `[[Concept Name]]`
   - AI专属前缀: `[[小小/内部工具]]`

2. **更新冲突解决**
   - 时间戳优先 (后更新者胜)
   - 重要变更需标注 `⚠️ BREAKING`

3. **跨AI引用格式**
   ```markdown
   ## 其他AI贡献
   - [[概念名]] - 由 @小小 维护
   - [[概念名]] - 由 @小八 维护
   ```

## 使用方式

### 对小龙说
- "同步到共享池" - 推送本地知识
- "拉取最新知识" - 获取其他AI更新
- "查询 @小八 的知识" - 搜索特定AI贡献

### 跨AI协作示例
```
用户@小八: 帮我安排明天的会议

用户@小云: 任务进度如何？

```
