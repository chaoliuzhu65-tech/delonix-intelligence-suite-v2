## 一、问题定义

### 现状痛点
| 痛点 | 影响 | 频率 |
|------|------|------|
| 预订信息非结构化（纯文字+截图） | 人工录入费时30-60min/天 | 每日 |
| 改名/续住/取消靠@人处理 | 容易漏单、响应慢 | 每日60+次 |
| 协议价格不统一 | 价格倒挂投诉、利润损失 | 偶发 |
| VIP偏好靠人记忆 | 服务不个性化、体验下降 | 高频VIP |
| 预订信息散落群聊 | 难以汇总统计、复盘 | 月度 |

### 目标
AI成为预订群的「**智能预订秘书**」，实现：
- 信息提取自动化
- 订单跟进主动化
- 客户记忆持久化
- 价格校验实时化

## 二、客户档案记忆系统（已就绪 ✅）

### 已建立
- 路径：`kb/客户档案/客户档案知识库.md`
- 数据量：18个协议客户档案
- 覆盖：价格体系、付费方式、服务要求、联系人、历史入住人

### 调用逻辑
```
收到新预订文本 
→ 识别客户名/公司名 
→ 查询档案库匹配协议价格 
→ 自动标注特殊要求（水果/晚餐/APP下载） 
→ 生成结构化卡片 
→ 推送群聊+@前台
```

## 三、MVP功能设计（分阶段）

### 🔴 P0 - 最核心（1-2周可上线）

#### F1: 自然语言预订信息提取
**输入**：
```
浩海船务：船名：MINERAL WALCOTT
定1个大床，今天3.24入住，3.25退房
公司付费，按458签单
```

**输出**（AI自动生成卡片）：
```
【预订信息提取】✅ 已识别
🏢 客户：浩海船务（档案已匹配）
📅 入住：2026-03-24
📅 退房：2026-03-25
🛏️ 房型：开元大床 × 1
💰 价格：240元/间夜（协议价）
📋 付费：公付签单（签458格式）
🍽️ 餐标：待确认（建议100元/人/餐）
📝 特殊：船名—MINERAL WALCOTT
⚠️ 建议：今晚到达，提前预留房间
👤 录入人：@张鑫 请确认并录入PMS
```

**技术方案**：
- 模型：千问3（支持结构化输出JSON）
- Prompt：预设提取模板 + 客户档案RAG
- 触发：识别到预订关键词（定房、入住、订X间等）

#### F2: 操作意图识别（改名/续住/取消）
**输入**：
```
改名
改名，升级海河套
这个取消了
```

**输出**：
```
【操作识别】✅
🎯 操作类型：改名 + 升级
📋 操作指令：请将XXX订单升级为海河套房
👤 执行人：@张鑫
⏰ 要求：尽快处理
```

#### F3: 每日预订汇总推送
**定时**：每天21:00自动推送
```
【今日预订汇总】2026-03-24
📥 新增预订：8条
  ├─ 浩海船务 ×2（公付）
  ├─ 火箭军VIP ×4（自付）  
  ├─ 天津通信中心 ×5（团队）
  └─ 其他 ×2
⚠️ 待处理：3条（待确认）
📋 操作记录：改名5次、续住2次、取消1次
💰 应收金额：约12,800元
```

**技术方案**：
- 每日定时扫描群聊（20:00-21:00消息）
- NLP提取所有预订相关消息
- 生成汇总卡片推送

## 八、风险与注意事项

1. **隐私**：客户姓名/电话不写入群聊卡片，仅供内部处理
2. **准确率**：初期需人工复核，AI准确率>95%后再全自动化
3. **权限**：仅读取群聊消息，不对外发送（由飞书机器人代发）
4. **学习**：每次前台纠错后，更新知识库（持续学习）
