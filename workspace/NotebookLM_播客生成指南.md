# NotebookLM 播客生成操作指南

> **说明**: 由于当前环境的技术限制，NotebookLM 需要通过浏览器手动操作。以下是详细步骤。

---

### 1. 确认登录状态
- 访问 https://notebooklm.google.com
- 确认已登录 Google 账号
- 您提到已在浏览器登录，应该可以直接使用

### 2. 准备内容源
已为您准备好以下内容文件：
- `播客内容_神灯AI_5-8分钟版.txt` - 完整播客脚本
- `podcast_script_guarded.txt` - Guardian生成的结构化版本

---

## 操作步骤

### 步骤1: 创建 Notebook

1. 访问 https://notebooklm.google.com
2. 点击 **"新建 Notebook"** 或 **"+"** 按钮
3. 输入标题：`神灯AI案例 - 德胧集团天津瑞湾酒店`

### 步骤2: 添加内容源

1. 点击 **"添加源"** 或 **"+ Add source"**
2. 选择 **"粘贴文本"** (Paste text)
3. 复制以下内容粘贴：

```
德胧集团神灯AI案例研究

【项目背景】
2026年3月30日，德胧集团正式发布神灯AI系统，这是酒店行业AI落地的重要实践。

【实施单位】
天津瑞湾开元名都酒店
负责人：晁留柱

【服务闭环】
1. 需求感知：客人通过百达屋APP或语音发起需求
2. 智能调度：AI系统自动识别需求类型和紧急程度
3. 人力执行：自动派单给最近的服务员
4. 数据回流：所有操作记录在系统中，形成数据资产

【核心数据】
• 入住速度：从15分钟缩短到10秒（提升90倍）
• 工单处理效率：提升83%
• 竞对分析效率：提升98%
• 知识库填充效率：提升500%
• 投资回报率：948%

【真实案例】
一位商务客人深夜抵达，通过APP发起加床需求。传统流程需要15-20分钟，神灯AI系统在10秒内完成派单，5分钟后服务员就已经敲门服务。客人评价："你们酒店的服务速度，比我在家还快。"

【价值主张】
德胧的神灯AI正在用数据和实践，证明AI在酒店行业的真正价值。技术最终回归服务本质——让客人感受温暖，让员工工作轻松。
```

4. 点击 **"添加"** 或 **"Add"**
5. 等待系统处理（约10-30秒）

### 步骤3: 生成播客 (Audio Overview)

1. 在 Notebook 界面找到 **"Notebook Guide"** 区域
2. 点击 **"Audio Overview"** 或 **"生成音频概览"**
3. 配置选项：
   - **语言**: 中文 (Chinese)
   - **格式**: 选择 **"Deep Dive"** (深度探讨) 或 **"Brief"** (简要版)
   - **自定义指令** (可选): 
     ```
     生成一个5-8分钟的双人对话播客，
     一位主播是女声（晓晓），一位是男声（云飞）。
     对话要自然、生动，像真实的电台节目。
     重点突出效率提升数据和投资回报率。
     ```

4. 点击 **"生成"** 或 **"Generate"**
5. 等待生成（约2-5分钟）

### 步骤4: 生成信息图 (Infographic)

1. 在 Notebook Guide 中滚动找到 **"Infographic"** 选项
2. 如果没有，点击 **"查看更多"** 或 **"+"**
3. 选择 **"生成信息图"**
4. 配置：
   - **风格**: 专业商务风格
   - **重点**: 核心数据（效率提升、ROI）
5. 点击生成
6. 等待生成（约1-3分钟）

### 步骤5: 下载成果

#### 下载播客
1. 播客生成完成后，点击播放试听
2. 点击 **"下载"** 或 **三个点菜单 → 下载**
3. 格式为 MP3

#### 下载信息图
1. 信息图生成后，点击放大查看
2. 右键 → **"保存图片"** 或点击下载按钮
3. 格式为 PNG

## 高级技巧

### 优化播客质量

**如果第一次生成不满意：**

1. **调整自定义指令**：
   ```
   请增加更多互动感，让对话更自然。
   主播A应该更有激情，主播B更沉稳。
   在提到948% ROI时要强调这是酒店行业的突破。
   ```

2. **添加更多源**：
   - 上传相关PDF文档
   - 添加网页链接
   - 粘贴更多背景资料

3. **选择不同格式**：
   - **Deep Dive**: 详细探讨（8-10分钟）
   - **Brief**: 简要版（3-5分钟）
   - **Debate**: 辩论形式
   - **Critique**: 批判性分析

### 生成视频版本

NotebookLM 还支持生成视频：
1. 在 Notebook Guide 中找到 **"Video Overview"**
2. 选择动画风格和配音
3. 生成后下载 MP4

## 故障排除

| 问题 | 解决方案 |
|------|---------|
| 无法添加源 | 检查网络连接，刷新页面重试 |
| 生成按钮灰色 | 等待源文件处理完成（看进度条） |
| 生成失败 | 尝试减少源文件数量，或简化内容 |
| 中文发音不自然 | 这是AI限制，可以尝试调整自定义指令 |
| 音频太长/太短 | 在自定义指令中明确指定时长要求 |
