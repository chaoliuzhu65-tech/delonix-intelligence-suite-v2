### NotebookLM CLI 研究（16:52-17:00）

**问题**：NotebookLM CLI 登录卡在 playwright install chromium
- 国内服务器无法访问 Google CDN（镜像华为源也损坏）
- 服务器在Miaoda云电脑（大陆），无法访问 notebooklm.google.com
- 用户Mac本地虽有VPN，但 playwright install 一直超时

**发现**：
1. 用户本地有 SID cookie（通过 console.log(document.cookie) 获取）
2. 但 Chrome cookies 数据库的 value 是加密的（BLOB），sqlite3 读不出原文
3. localStorage 里 lm_metadata 取不到 token（not_found）

**结论**：NotebookLM 认证方案在此环境中走不通（网络限制+加密cookie）

**沉淀**：NotebookLM 本地安装认证流程（Mac）：
- pip install notebooklm-py
- playwright install chromium
- notebooklm login
- storage_state.json 在 ~/.notebooklm/
