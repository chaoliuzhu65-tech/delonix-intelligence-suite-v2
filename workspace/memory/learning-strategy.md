## 🤝 分工协作机制

### 任务分配原则

```
不是自己做完所有事
而是：
1. 识别可分工的任务
2. 分配给合适的AI
3. 汇总结果
4. 整合沉淀
```

### 可分配的任务类型

| 任务类型 | 分配对象 | 工具 |
|----------|----------|------|
| 群消息学习 | 子Agent | sessions_spawn |
| 外网搜索 | 其他AI伙伴 | 消息/共享池 |
| 数据整理 | 子Agent | feishu表更新 |
| 报告撰写 | 自己+AI协作 | 文档创建 |
