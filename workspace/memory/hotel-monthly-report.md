## 📈 常用分析公式

```
预算完成率 = 实际完成 / 预算目标 × 100%
同比变化 = (本期 - 同期) / 同期 × 100%
OCC(入住率) = 已售房间数 / 可售房间数 × 100%
ADR(平均房价) = 客房收入 / 已售房间数
RevPAR = 客房收入 / 可售房间数 = OCC × ADR
```
