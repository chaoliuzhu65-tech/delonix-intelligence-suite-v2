# Shared Pool - 多AI协作共享池

## 核心功能

### 1. 双向同步
- **上传**: 本地 wiki/ → 飞书多维表格
- **下载**: 飞书多维表格 → 本地 wiki/
- **冲突处理**: 时间戳优先，版本控制

### 2. AI 伙伴管理
- 注册/发现同一租户下的其他 OpenClaw 实例
- 维护 AI 状态 (在线/离线/最后同步)
- 跨 AI 查询和引用

### 3. 变更广播
- 知识更新自动通知其他 AI
- 支持 webhook 和轮询两种模式

## 命令列表

### 用户指令

| 指令 | 功能 | 示例 |
|------|------|------|
| "同步到共享池" | 推送本地知识到中央 | 同步所有 wiki/ 文件 |
| "拉取最新知识" | 获取其他 AI 的更新 | 下载并合并远程变更 |
| "查询 @昵称 的知识" | 搜索特定 AI 贡献 | 查询 @小八 的同步方案 |
| "查看 AI 伙伴状态" | 显示所有 AI 状态 | 在线/离线/同步时间 |
| "强制全量同步" | 双向全量对比同步 | 解决冲突 |

### 自动触发

- **本地变更**: 检测到 wiki/ 文件修改 → 自动上传
- **远程变更**: 收到飞书 webhook → 自动下载
- **定时任务**: 每15分钟双向检查

## 同步策略

### 上传流程
```
1. 扫描本地 wiki/ 所有文件
2. 计算每个文件的 hash/timestamp
3. 对比共享池版本
4. 上传变更文件
5. 更新共享池索引
6. 广播变更事件给其他 AI
```

### 下载流程
```
1. 查询共享池变更日志
2. 筛选其他 AI 的更新
3. 下载新/更新的概念
4. 合并到本地 wiki/
5. 更新本地索引
6. 通知用户新内容
```

## 技术实现

### 存储后端
- **飞书多维表格**: 概念库主存储
- **飞书文档**: 富文本内容 (可选)
- **本地文件**: 各 AI 本地缓存

### 同步协议
- **鉴权**: 飞书 App Token (同一租户共享)
- **通知**: 飞书 webhook + 消息卡片
- **数据格式**: Markdown + JSON 元数据
