# 卡帕西风格知识库进化系统

## 核心流程

### 1. 检测变更
```bash
# 检查 raw/ 目录是否有新文件
find workspace/kb/raw -type f -newer workspace/kb/.last_processed 2>/dev/null || echo "首次运行"
```

### 2. 处理原始资料
对于每个 raw/ 中的文件：
1. **阅读内容** - 使用 file_read 或 image_understanding
2. **生成摘要** - 提取核心观点
3. **提取概念** - 识别关键术语
4. **创建 wiki 条目** - 写入 wiki/ 目录
5. **建立链接** - 在相关概念间创建反向链接

### 3. Wiki 维护规则
- 概念文件使用 `[[Concept Name]]` 链接
- 每个概念文件包含：定义、来源链接、相关概念
- README.md 自动更新为知识图谱索引
- 避免重复：同名概念合并而非新建

### 4. 与飞书集成
- 飞书文档/消息可一键存入 raw/
- Wiki 内容可推送回飞书多维表格
- 支持飞书搜索查询知识库

## 使用示例

用户："整理一下今天的会议记录"
→ 处理 raw/2024-04-07-meeting.md
→ 提取决策、行动项、相关项目
→ 更新 wiki/项目管理.md 和 wiki/待办事项.md
→ 生成摘要回复用户

用户："搜索关于 OpenClaw 的配置"
→ 查询 wiki/OpenClaw.md 及相关链接
→ 返回结构化答案
