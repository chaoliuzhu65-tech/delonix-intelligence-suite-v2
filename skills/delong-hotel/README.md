# 德胧酒店AI工具库

这是德胧酒店集团为店总们准备的8个AI助手技能。

## 技能列表

| 序号 | 技能名称 | 功能描述 | 触发关键词 |
|------|----------|----------|------------|
| 1 | 值班日志助手 | 一句话生成标准化值班日志 | 值班日志、日志、生成日志、交接班 |
| 2 | 客诉处理助手 | 智能分类客诉，生成处理流程 | 客诉、处理投诉、客人投诉 |
| 3 | 房态预测助手 | 预测未来房态，给出定价建议 | 房态、预测、入住率 |
| 4 | 质检评分助手 | 分析质检录音，多维度评分 | 质检、评分、检查 |
| 5 | 排班助手 | 智能生成排班表 | 排班、班次 |
| 6 | 应急预案助手 | 快速生成各类应急预案 | 应急、预案、突发事件 |
| 7 | 巡检助手 | 生成标准化巡检报告 | 巡检、检查、巡房 |
| 8 | 客情提醒助手 | VIP客人生日/纪念日提醒 | 客情、VIP、客人提醒 |

## 使用方式

### 方式一：妙搭平台导入
1. 打开妙搭Studio
2. 创建新Bot
3. 逐个导入这8个Skill

### 方式二：飞书群聊调用
1. 把Bot邀请到飞书群
2. 使用触发词激活对应技能

### 方式三：直接对话
1. 在妙搭/飞书中与Bot对话
2. 直接说出需求（如"帮我处理客诉"）

## 示例对话

**用户**: 帮我生成今天的值班日志

**Bot**: 好的，我来帮你生成值班日志。请提供以下信息：
1. 值班人姓名：
2. 班次（早班/中班/晚班）：
3. 今日重要事件（客诉、维修等，可略过）：

---

**用户**: 处理客诉：客人投诉房间空调太吵

**Bot**: 
📋 客诉处理方案

**客诉分类**: 设施类-噪音

**标准回复话术**:
"非常抱歉给您带来不便，我们高度重视这个问题..."

**处理流程**:
1. 立即致歉，记录客人信息
2. 协调换房（优先同楼层静音房）
3. 赠送早餐券表示歉意
4. 记录CRM系统

**CRM记录提醒**: 请在系统中记录客诉编号：XXXX
